| PART 2: PATH-SPECIFIC REASSESSMENT QUESTIONS |
| :---: |

At the 90-day reassessment, four optional reflection questions appear after the 16 scored questions. These are not scored. They feed the AI context block and the PDF report. One of the four questions — Question 4 — is path-adaptive: if the user has completed one or more full paths, it is replaced with a question specific to the most recently completed path.

|  | LOGIC FOR IMPLEMENTATION IF user has completed\_paths\_count \>= 1 THEN show path-specific variant for most\_recently\_completed\_path ELSE show standard Question 4\. The path name is dynamically inserted into the question text. Dr. Sam has written one question per path — all 55 variants are in this document. |
| :---- | :---- |

# **Section 3 — Standard Reflection Questions (all users)**

These four questions appear for all users at reassessment. Question 4 is replaced by a path-specific variant when applicable.

| Question 1 (always shown) | Looking back at the past 90 days, what has shifted most in how you show up — even if the change is small? |
| :---- | :---- |

| Question 2 (always shown) | What has been the hardest part of this period, and what does that tell you about what you most need right now? |
| :---- | :---- |

| Question 3 (always shown) | What are you most ready to let go of, change, or move past as you head into the next 90 days? |
| :---- | :---- |

| Question 4 (default — shown when no paths completed) | If you could name one thing that would make the next 90 days meaningfully different from the last 90, what would it be? |
| :---- | :---- |
