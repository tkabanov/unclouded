# **How to Use This Document**

This document contains the complete results screen copy for all seven PuP 360 classifications. Each section maps to one classification and includes every text element that appears on the results screen: the screen header, the classification name and tagline, the score display note, the tradeoff statement, the 'What This Means' block, the focus areas, and the recommended paths.

The copy is written for the exact user state each classification represents. Do not swap copy between classifications.

### **Dynamic elements — pull from database:**

•  First Name — pulled from User record at display

•  Score values — pulled from latest AssessmentResult record (Stability, Performance, Alignment)

•  Score color coding — applied by comparison against thresholds: below 3.2 \= amber/red, 3.2–3.7 \= neutral gray, 3.8+ \= green

•  Recommended paths — top 2 paths from the user's auto-assigned path list based on classification engine output

### **Static elements — hardcoded per classification:**

•  Classification name and tagline

•  Tradeoff statement

•  What This Means copy

•  Focus areas (3 bullets)

|  | DISCLAIMER NOTE The standing disclaimer appears at the bottom of every results screen regardless of classification. It is always the same text.
